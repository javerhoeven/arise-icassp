# ARISE: Adaptive Residual Implicit Sound-field Estimator

 Companion code for the paper *"Time-Domain PINNs for the Spatial Interpolation of Room
 Impulse Responses"*.

 The code in this repository contains the evaluation data reported in the paper and reproduces the results, tables and figures. 
 
 The code is not yet public. It will be released here, under the MIT License, upon
 acceptance of the paper.
